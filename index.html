Vesselgrid: berth plans that move with the ships

Vesselgrid is AI berth scheduling software for port terminal operators, shipping lines and harbor service providers. It combines AIS vessel positions, marine weather and historical port congestion to predict vessel arrival times, sequence berths against length, draft, cargo and crane constraints, and schedule tugs and pilots from the same plan.

Core capabilities

  • Predictive ETA engine
  • Dynamic berth scheduler
  • Congestion risk analytics with a 72-hour outlook
  • Tug and pilot dispatch planning
  • AI-written shift summaries and risk reports

How We Use Amazon Web Services

Vesselgrid's architecture is designed on Amazon API Gateway, AWS Lambda, Amazon S3, Amazon SageMaker, Amazon DynamoDB and Amazon Bedrock.
